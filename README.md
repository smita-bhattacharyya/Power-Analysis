# Power-Analysis
My projects during learning and practicing skills to collect, modify and analyze data from various data sources. 

| Project Name | Context |
|--------------|---------|
|[Power BI - Analysis - on Sales](https://github.com/smita-bhattacharyya/Power-Analysis/blob/main/Power%20BI%20-%20Analysis%20-%20on%20Sales.pdf) | Analysis on Sales data :- Average discount by promotion categories is represented through a bar chart, Sales by City is represented by Map visual, Total number of orders is represented by a card visual, Sales Trends by Period is represented by Line Chart, Profit V/s Net Sales is represented by a scattered chart. Different visuals are used to represent the data distribution with different conditions.

[Power BI- Analysis - on Insurance Data] | [Analysis on Insurance Data :- A beautiful report was created after analyzing the insurance data of a company. A multi row card is created to represent the count of customers with a specific gender. Three card visuals are used to tell about sum of Premium Amount, Total Coverage Amount and Total Claim Amount. A bar Chart is used to represent the sum of premium amount values by each of the policy categories. A Donut Chart is used to represent the total number of active and inactive customers. A ribbon chart is used to show the number of claims by claim status. A line chart is used to show the total claim amount by each of the age group. A table is used to show different data features regarding different policy type. A bar chart is used to represent the count of customers by different feedback. Another table visual is used to represent each customer and his/her feedback.]
