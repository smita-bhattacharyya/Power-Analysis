# Power-Analysis
My projects during learning and practicing skills to collect, modify and analyze data from various data sources. 

| Project Name | Context |
|--------------|---------|
|[Power BI - Analysis - on Sales](https://github.com/smita-bhattacharyya/Power-Analysis/blob/main/Power%20BI%20-%20Analysis%20-%20on%20Sales.pdf) | Analysis on Sales Data :- Average discount by promotion categories is represented through a bar chart, Sales by City is represented by Map visual, Total number of orders is represented by a card visual, Sales Trends by Period is represented by Line Chart, Profit V/s Net Sales is represented by a scattered chart. Different visuals are used to represent the data distribution with different conditions. **This report tells about the sales, profit and places (e.g. Bangalore) where sales need to be improved.** |
|[Power BI- Analysis - on Insurance Data](https://github.com/smita-bhattacharyya/Power-Analysis/blob/main/Power%20BI-%20Analysis%20-%20on%20Insurance%20Data.pdf) | Analysis on Insurance Data :- A beautiful report was created after analyzing the insurance data of a company. A multi row card is created to represent the count of customers with a specific gender. Three card visuals are used to tell about sum of Premium Amount, Total Coverage Amount and Total Claim Amount. A bar Chart is used to represent the sum of premium amount values by each of the policy categories. A Donut Chart is used to represent the total number of active and inactive customers. A ribbon chart is used to show the number of claims by claim status. A line chart is used to show the total claim amount by each of the age group. A table is used to show different data features regarding different policy type. A bar chart is used to represent the count of customers by different feedback. Another table visual is used to represent each customer and his/her feedback.**This report tells us about the total amount, remaining balance, customer feedback and how many customers gave feedback as 'excellent'** |
|[Power BI - Analysis - on UPI Transactions](https://github.com/smita-bhattacharyya/Power-Analysis/blob/main/Power%20BI%20-%20Analysis%20-%20on%20UPI%20Transactions%20.pdf) | Analysis on UPI Transaction Data :- A Column chart is used to represent total remaining balance by month. Multiple multi paged filters are used to make it easier for the user to filter the data according to his/her need. A table visual is created to represent total amount, remaining balance by different cities, currency and months. **This report tells us that remaining balance was highest in June 2024 and was lowest in January and May, it also can filter with multiple filter on it.**|
